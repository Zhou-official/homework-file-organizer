# 作业文件批量归档工具
## 项目简介
本项目是一个使用 Python 编写的作业文件批量整理脚本。
主要用于扫描、重命名和归档 PDF、DOCX 等作业文件，
并支持生成整理报告和撤销上一次操作。

## 功能
### 1. 文件扫描
可以扫描指定文件夹，并显示：
- 文件名
- 文件大小
- 修改时间
同时支持按扩展名筛选，例如：
- `.pdf`
- `.docx`
### 2. 批量改名
支持将：
`学号_姓名_作业名.pdf`
修改为：
`作业名_学号.pdf`
程序在真正改名前会先显示修改预览。
只有用户确认后才会执行修改。
如果新文件名已经存在，程序会自动添加数字后缀，
避免覆盖已有文件。
例如：
`数据分析作业_20260001.pdf`
如果已经存在，会生成：
`数据分析作业_20260001_1.pdf`
### 3. 文件归档
用户可以按照学期或类别创建子文件夹，例如：
`2026秋季`
或：
`数据分析`
程序会将支持的作业文件移动到对应子文件夹。
### 4. 整理报告
完成操作后，程序会生成：
`整理报告.txt`
报告包括：
- 成功处理文件数量
- 跳过文件数量
- 跳过原因
### 5. 撤销功能
程序会保存上一次批量操作。
如果发生错误，可以选择：
`撤销上一次操作`
恢复修改前的文件。
## 支持文件类型
目前支持：
- PDF (`.pdf`)
- Word (`.docx`)
## 运行环境
Python 3.x
本项目仅使用 Python 标准库，
不需要额外安装第三方库。
